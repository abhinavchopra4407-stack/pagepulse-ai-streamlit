# ⚡ PagePulse AI — Smart Page-by-Page PDF Summarizer & RAG Assistant

A high-performance Streamlit web application designed to summarize PDF documents page-by-page, extract executive TL;DRs, key highlights, time-saving statistics, and enable instant semantic RAG document search.

## 🚀 Deployed on Streamlit Community Cloud

### 📦 Setup & Local Testing

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Run Streamlit app:
   ```bash
   streamlit run app.py
   ```

### 🌐 Deploying to Streamlit Community Cloud (Step-by-Step)

1. **Create a GitHub Repository**:
   - Push this directory (`app.py`, `requirements.txt`, `.streamlit/config.toml`, `README.md`) to a new public GitHub repository.

2. **Deploy on Streamlit**:
   - Log into [Streamlit Community Cloud](https://share.streamlit.io).
   - Click **"New app"**.
   - Select your GitHub repository, branch (`main`), and set **Main file path** to `app.py`.
   - Click **"Deploy!"**.
